## 发现项

### F-01（高）主 CTA 文字为白色，偏离 DESIGN.md 且对比度不足

- 证据：登录/注册/404/案例库/详情/新建/个人中心/admin 各页的青色实心按钮。
- 实测：`color: rgb(255,255,255)`、`background: rgb(59,166,241)`。
- DESIGN.md《Agent Prompt Guide》第 2 条明确：主操作按钮 = `#3ba6f1` 背景 + `#0c0a09` 文字。
- 对比度：白字约 2.66:1（低于 WCAG AA 4.5:1）；墨黑字约 7.45:1。
- 建议：`Button` 的 `primary` 变体改为 `text-ink-black`，全站一处生效。

### F-02（低）文件选择控件保持浏览器原生外观

- 证据：`11-user-case-new.png`、`11-user-case-detail.png` 的「选择文件 / 未选择任何文件」。
- 原生控件与药丸/细线语言不一致；受浏览器样式限制，可接受或仅统一外层容器。

### F-03（中）「下载附件」使用煤黑实心，占用了破坏性操作的语义

- 证据：`11-user-case-detail.png`。
- spec 的按钮体系：墨黑实心 + 二次确认 = 删除分类/禁用账号等不可逆操作；下载是可重复的次级动作。
- 建议：改为墨黑描边（`outline`），与「驳回」同级；页面的青色主行动仍为「重新提交」。
